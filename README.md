A full-stack Customer Relationship Management system designed to manage leads, customers, and users through a centralized dashboard.

**Key Features:**

- 🔐 JWT-based Authentication
- 👥 Admin & User Role-Based Access
- 🛡️ Protected Routes
- 📊 CRM Dashboard
- 🧑‍💼 Lead Management
- 👤 Customer Management
- 🔄 Lead-to-Customer Conversion
- ✏️ Create, Read, Update & Delete operations
- 🔎 Search & Pagination
- 🌐 REST API integration
- 🗄️ MySQL Database Integration

**Tech Stack**
